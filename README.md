🕵️ NetSpy - Network & Vulnerability Scanner
Created with ❤️ by Leon

NetSpy is a powerful and interactive command-line tool designed for network reconnaissance, port scanning, OS detection, and vulnerability assessment on Linux-based systems.

It provides a professional, menu-driven interface for cybersecurity students, ethical hackers, and penetration testers to scan local networks and identify potential weaknesses in connected devices.

✨ Features
✅ Network Device Discovery using ARP

🌍 Hostname Resolution and Geo-IP / ISP lookup

🔍 Port Scanning with open port detection

🧠 OS Fingerprinting via Nmap's -O detection

🔥 Risk Scoring System (Low / Medium / High)

🧪 Vulnerability Scanning using Nmap scripts

❗ Security Disclaimer Prompt (Permission Check)

🧼 Input Validation to prevent invalid entries

🖥️ Designed for Linux CLI environments with full sudo support

⚙️ How to Use
Clone the repository

git clone https://github.com/drLee0011/netspy.git
cd netspy
Create and activate virtual environment

python3 -m venv venv
source venv/bin/activate
Install dependencies

pip install -r requirements.txt
sudo apt install nmap
Run the tool

sudo venv/bin/python3 main.py
